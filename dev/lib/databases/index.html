Databases

A Database (database identifier) is a handle to one B-tree inside an environment. By default an env has a single anonymous database (the "main DB"); pass maxdbs > 0 to Environment and a name to the Database constructor to work with multiple named sub-databases.

Construction

LMDB.Database — Type

A database handle within an LMDB environment.

source
LMDB.Database — Method
Database(txn::Transaction, dbname::AbstractString = ""; flags=0) -> Database

Open dbname in txn; an empty name selects the main database. flags may include database options such as MDB_CREATE and MDB_DUPSORT.

Reads

Base.get — Method
get(txn::Transaction, dbi::Database, key, ::Type{T}) -> T

Read the value at key, decoded as T. Throws LMDBError if key isn't there, the same as d[k] on a regular AbstractDict.

source
Base.get — Method
get(txn::Transaction, dbi::Database, key, ::Type{T}, default) -> Union{T,typeof(default)}

Read the value at key, decoded as T; return default if the key isn't there. Mirrors Base.get(dict, key, default). Pass nothing as default for the Union{T,Nothing} form.

source

get(txn, dbi, key, T, default) falls back to default if key is missing, matching Base.get(dict, key, default).

Writes

Base.put! — Method

Store val at key.

source
LMDB.put_reserved! — Function
put_reserved!(f, txn::Transaction, dbi::Database, key, size::Integer; flags=0)

Reserve size bytes of LMDB-managed value storage at key and call f with a Vector{UInt8} view of it. The view is valid only during f; fill every byte and do not retain it. MDB_RESERVE is not valid for MDB_DUPSORT databases.

source
Base.delete! — Method
delete!(txn::Transaction, dbi::Database, key) -> Bool
delete!(txn::Transaction, dbi::Database, key, val) -> Bool

Delete key (or, in MDB_DUPSORT, the specific (key, val) pair) from the database. Returns true if an entry was removed, false if the key was not present. Other LMDB errors propagate as LMDBError.

This method does not throw for MDB_NOTFOUND.

source
Base.replace! — Method
replace!(txn::Transaction, dbi::Database, key, val, ::Type{V}=typeof(val))
    -> Union{V,Nothing}

Atomically write val at key, returning the previous value (decoded as V) or nothing if key was not present. Read and write share the same transaction.

source
Base.pop! — Method
pop!(txn::Transaction, dbi::Database, key, ::Type{T}) -> Union{T,Nothing}

Atomically read and delete the value at key, returning it (decoded as T) or nothing if key was not present.

source

Write flags

The flags keyword on put! accepts a bitwise-or of:

flagmeaning
MDB_NOOVERWRITEfail with MDB_KEYEXIST if key is already present
MDB_NODUPDATA(DUPSORT) fail if (key, val) pair already present
MDB_APPENDappend at the end; only valid if the new key sorts after every existing key
MDB_RESERVEpreferred via put_reserved!

See also the DUPSORT-only ops on the cursor surface.
